# pi-setup

My personal [pi](https://pi.dev) coding agent configuration.

## What's inside

- `settings.json` — pi config (provider, model, theme, etc.)
- `skills/` — custom skills (grow over time)
- `themes/` — custom themes
- `prompts/` — custom prompt templates

## Install

```bash
pi install /absolute/path/to/pi-setup
# or from GitHub:
pi install git:github.com/YOUR_USER/pi-setup
```
